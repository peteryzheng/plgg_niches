# Presentation — Spatial Architecture of Pediatric Brain Tumors

`plgg_xenium_deck.pptx` is the deck. It is generated by `build_deck.js` (pptxgenjs);
figures and H&E are embedded from `assets/`.

## Rebuild
```
cd presentation
NODE_PATH="$(npm root -g)" node build_deck.js   # -> plgg_xenium_deck.pptx
```
Requires Node + a global `pptxgenjs` (`npm i -g pptxgenjs`). `build_deck.js` resolves
`assets/` relative to itself and writes the `.pptx` next to itself.

## Contents
- `build_deck.js` — deck generator: slides, layout, and the drawn pipeline cartoons
  (ProSeg / BANKSY / ENVI / STalign) as vector shapes.
- `assets/` — images embedded in the deck:
  - `fig_*.png` — analysis figures pulled from rendered notebook HTMLs:
    cell-type & niche composition bars + both enrichment forests
    (`niche/proseg_output_analysis/celltype_niche_histology_enrichment.html`), and the
    "ecosystems" 4×4 heatmap (`.../niche_interpretation_proseg.html`).
  - `thumb_{PA,GG,CN,CLN}.jpg` — H&E thumbnails, one per tumor histology.
  - `pa_biphasic_slide_annot.jpg` — PA biphasic H&E, compact=green / loose=blue (slide 2).
- `src/` — provenance/dev scripts (paths are dev-local; kept for reference):
  - `preview.js` — standalone render of the four cartoons.
  - `crop_he.py`, `assets_he.py`, `overview_he.py` — H&E cropping. GeoJSON→JPG scale = **/7**
    (per the STalign qmds); source images `data/Xenium_annotations/images/230918_Xenium_CytAssist_LGG{1,2}.jpg`.
  - `extract_figs.py` — regex-extract embedded PNGs from a rendered quarto HTML
    (`python extract_figs.py <deck.html> <outdir>`); identify figures by qmd order + native dims.

## Refresh a figure
Re-render the source notebook, then `python src/extract_figs.py <rendered.html> /tmp/figs`,
pick the right `img_NN.png` (by figure order / dimensions), copy over the matching
`assets/fig_*.png`, and rebuild.
